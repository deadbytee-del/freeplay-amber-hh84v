Userscripts

Userscripts are small scripts that run on a page as it opens in the Browser tab, like Tampermonkey. Each one says which sites it runs on and when. Use the puzzle button in the Browser to switch them on and off.

Add a userscript

Opening a .user.js address in the Browser tab offers to install it. Supported: @match, @include, @exclude, @run-at, @require, and the GM_ functions (storage, addStyle, xmlhttpRequest, openInTab, menu commands). Turning a script off fully applies when the page reloads.

Proxy sites

LiTeer.exe can also run these open-source proxies as their own separate sites. Start them from the Proxy sites tab in LiTeer.exe, then open them here.
